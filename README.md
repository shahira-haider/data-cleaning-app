# 🧹 Data Cleaning App

An interactive Streamlit web application for cleaning and preprocessing CSV datasets. This tool helps users handle missing values, remove duplicates, fix data types, and prepare datasets for data analysis.

## ✨ Features

* Upload CSV datasets
* Missing value detection & handling
* Remove duplicate records
* Data type conversion
* Column management
* Download cleaned dataset
* Interactive data preview

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* NumPy

## 🚀 Run Locally

```bash id="jlwm6q"
pip install -r requirements.txt
streamlit run app.py
```
